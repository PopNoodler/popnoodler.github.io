Moles: Bomb Squad

Role: Solo Project  ·  Language: C++ & Blueprint Visual Scripting  ·  Engine: Unreal Engine 4

Moles: Bomb Squad is a competitive online FPS made to accompany the procedural level generator system that I created. The project reuses assets from King of the Drills to create a search-and-destroy based game type.

Notable skills

  • Using Unreal Engine's netcode to implement balanced gameplay using a server-client model.
  • Implementing a search-and-destroy based game loop.
  • Adding standard FPS features including shooting, aiming down sights and recoil.
  • Working with a class hierarchy for a hero-based system.
  • Optimisation considerations for a tile-based procedural environment.
